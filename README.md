# Student Management System

## 📖 Overview
The Student Management System is a software application designed to help manage student information efficiently. It allows users to store, update, retrieve, and organize student records in one place.

## ✨ Features
- Add new students
- View student records
- Update student information
- Delete student records
- Search for students

## 🛠️ Technologies
- Git
- GitHub
- Visual Studio Code

## 🚀 Getting Started

### Clone the repository
```bash
git clone <repository-url>
```

### Navigate to the project folder
```bash
cd Student-Management-System
```
